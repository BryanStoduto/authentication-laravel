# Executando o projeto

## 1. Iniciando o projeto

No terminal do VS Code, dentro da pasta do projeto, execute o comando abaixo para iniciar o servidor local:

```bash
php artisan serve
```

<img width="470" height="183" alt="image" src="https://github.com/user-attachments/assets/8d3ad6d9-26bb-45f9-be49-082d35dded11" />

<p>Comando utilizado para iniciar o projeto pelo terminal do VS Code.</p>

## 2. Acessando a página inicial

Após executar o comando, o terminal exibirá o endereço local do projeto.

<img width="421" height="102" alt="image" src="https://github.com/user-attachments/assets/e95fc0a9-6bac-4242-a921-b574659df1e8" />

<p>Clique no endereço exibido ou copie e cole o link abaixo no navegador:</p>

```text
http://127.0.0.1:8000
```
